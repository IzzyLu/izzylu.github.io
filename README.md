# Isabella Lu — Research & Tools

Personal research portfolio: [https://izzylu.github.io/](https://izzylu.github.io/)

The site introduces my work in experimental biology, gene regulation, and computational analysis, featuring ERG analysis and microscopy quantification.

## What is included

- `index.html`: the self-contained portfolio page, including responsive styles.
- `.nojekyll`: serves the page as static content.

This repository contains the portfolio website. Research software, experimental datasets, and trained microscopy classifiers are not included here.

## Updating the site

Edit `index.html` and commit the change to `main`. GitHub Pages publishes the root of that branch. No dependency installation or build command is needed. Open `index.html` in a browser for a local preview.
